System Overview
What is this software and why does AMAC need it?
In one sentence: This is a digital factory control system that tracks every aluminium casting — from the moment it is poured into a machine, through every quality and finishing department, all the way to the final delivery to the customer.

The Problem Today

Currently, AMAC tracks production using physical registers, verbal communication between departments, and Excel sheets. This creates several problems:

Manual Errors

  • Data entered incorrectly in registers
  • Calculations done by hand — wrong totals
  • No way to verify who entered what

No Visibility

  • Management cannot see live status
  • Rejection rates only known at month-end
  • Cannot track where a specific batch is

No Accountability

  • Cannot trace which operator made a defective part
  • No department-wise performance history
  • Disputes during customer complaints

Planning Gaps

  • Targets not clearly communicated to floor
  • No comparison of plan vs actual per shift
  • No daily efficiency measurement

How This System Solves It

Every person in the factory — from the casting operator to the final inspector — has their own dedicated login. They record their work digitally. The system automatically:

  • Calculates efficiency, rejection percentage, and good output
  • Generates a unique tracking number for every batch of parts
  • Shows management a live dashboard with real factory data
  • Lets Admin compare planned targets vs actual output — daily, weekly, monthly
  • Traces any part's complete journey in seconds

System Structure

Browser Screen

What users see and interact with. Works on any computer or tablet in the factory.

Application Server

Handles all the calculations, rules, and communication between screen and database.

SQL Server Database

Stores all data permanently and securely. Backed up automatically.

Admin (Management)

One account — Full access to everything.

  • Approve or reject department entries

6 separate accounts — Each sees only their own screen.

  • Log in with department-specific username & password
  • Only their department screen opens — nothing else
  • Enter production or processing data for their shift

  • Cannot access Reports, Dashboard, or Admin Panel

Complete Data Flow — Zero to End
How information moves through the system from setup to dispatch
1

One-Time Setup — Admin configures the system

Before operations begin, the Admin enters the master reference data. This is done only once and updated when things change.

  • Parts Master: Part Number, Part Name, Customer, Shot Weight, Casting Weight, Cycle Time, Output per Machine per Shift, whether it needs Core or Heat Treatment, Dispatch Location.
  • Supervisors: Name, active/inactive status.
  • Operators: Punch Number (unique ID), Name, Alias Letter (used in Traceability ID), Department, Shift, Supervisor assignment.
Admin Only Stored permanently in database
2

Planning — Admin sets targets before each period

Admin creates production targets at two levels:

  • Monthly Dispatch Plan: For each part, Admin enters how many pieces must be dispatched to the customer this month. This is the monthly target.
  • Daily Shift Plan: For each working day, Admin assigns — which part runs on which machine, in which shift, and how many pieces are expected. This is the daily target that operators are measured against.
Admin Only Updated daily/monthly
3

Production Entry — Supervisor logs actual casting data

At the end of each shift, the Production Supervisor logs in and enters what was actually produced:

  • Date, Shift (A / B / C), Supervising Supervisor
  • For each machine: Die/Machine Number, Part, Operator, Planned Qty (auto-fills from Daily Plan), Actual Qty produced, Rejection Qty

System automatically calculates: Good Qty = Actual – Rejection | Efficiency % = (Actual ÷ Planned) × 100 | Rejection % = (Rejection ÷ Actual) × 100

Unique Traceability ID is generated (e.g., AMAC-20260921-SA-M3-OP12). This number follows the parts through every department.

Auto-calculated KPIs Traceability ID generated Status: Submitted → Approved
4

Downstream Processing — 6 Departments log their work

Parts pass through subsequent departments. Each department supervisor logs in, enters their Traceability ID, and records:

  • How many pieces came in (Input Qty)
  • How many were rejected / found defective (Rejection Qty)
  • System calculates: Processed Qty = Input – Rejection

Each entry goes to Pending Approval → Admin approves or returns with comments → Approved entries become permanent records.

Rejection tracked per department Linked to Traceability ID 6 departments tracked
5

Dispatch → Reports → Management Decisions

Once parts reach the Storage & Dispatch department and are logged as dispatched, the complete cycle is closed. Admin can at any time:

  • Search any Traceability ID to see the full history of that batch
  • View planned vs actual by part, by shift, by date range
  • See rejection rates per department
  • Download everything as Excel reports
  • View live dashboard with today's production status
Live dashboard Excel export Full traceability

How to Search for a Part

A

Method 1: Global Search Bar (Top of every page)

Any Admin user types the Traceability ID in the search bar at the top of any screen and presses Enter. The system immediately opens the Traceability report for that batch.

B

Method 2: Reports → Traceability Tab

Admin opens Reports screen, goes to the Traceability tab, types or pastes the ID, and clicks Search.

Reports & Management Analytics
What management can see and measure at any time

Live Dashboard (Home Screen)

Auto-refreshes every 30 seconds. Shows for today:

  • Total pieces planned
  • Total pieces actually produced
  • Total rejections
  • Overall factory efficiency %
  • Charts: Good vs Rejection, Produced vs Dispatched

Overview Report

Filter by date range and shift. Shows:

  • Total planned target (sum of all shift plans)
  • Total actual achieved
  • Overall efficiency %
  • Total rejections across factory

Part-Wise Analytics

For each part number, shows:

  • How many planned
  • How many actually made
  • Plan Adherence % (with visual bar)
  • Total rejections and Rejection %
  • Highlighted in red if rejection > 5%

Department-Wise Performance

For each of the 6 tracked departments:

  • Total pieces processed
  • Total rejections at this stage
  • Rejection Rate %
  • Health badge: Healthy / Needs Attention / Critical

Traceability Search

  • Type any batch number
  • Instantly see full journey of that batch
  • Every stage, every operator, every quantity

Excel Export

  • Download complete production data as .xlsx
  • Includes all shifts, all parts, all dates
  • Ready for further analysis in Excel
